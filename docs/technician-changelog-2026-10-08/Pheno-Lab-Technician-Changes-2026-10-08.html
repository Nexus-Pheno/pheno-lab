CHANGE / 01

先定义实验组，再分配基片

实验组是方案的一部分。某组暂时没有基片时，仍可为它填写、保存和重新编辑工序参数。

反馈中的问题

部分组未分配基片后，工序面板只显示有基片的组；准备 A–E 五组条件时会缺少空组。

本次调整

  • 工序面板读取方案中的完整组列表，保留空组及其条件。
  • 新建基片批次默认全部进入备用区；可按准备进度拖入实验组。
  • 各组片数按实际分配自动统计，并显示已归组、备用、报废 / 问题数量。

使用方法

  1. 打开「定义实验方案」，设置基片总数，例如 17 片；按需要添加 A–E 五组。
  2. 填写每组的材料或参数条件。各组当前片数可为 0，不必先分配基片。
  3. 应用方案后，点击工序即可查看和编辑 A–E 的条件；保存并重开仍会保留。
  4. 准备好基片后，将其从「备用」拖入目标组。移回备用区时，组内片数也会更新。

同时修复：未选择可选设备时，方案可正常保存。已验证调整方案及移动基片时，已有样品身份、已记录证据及空组参数保留。

屏幕示例均为测试环境与虚构数据，不是生产实验截图。

CHANGE / 02

按编号或名称，找到旧方案

「从模板 / 以前的实验」取消最近 8 条限制，搜索覆盖当前账号原有可选范围内的历史实验。

反馈中的问题

列表只展示最近 8 条记录。更早的实验即使记得编号或名称，也无法在此找到。

本次调整

  • 新增搜索框，支持实验编号、名称的部分匹配，忽略英文大小写及首尾空格。
  • 搜索覆盖完整可选列表，历史记录每页 20 条；支持上一页、下一页和无匹配提示。
  • 保留置顶模板及原有权限范围；复制后生成新的草稿、实验编号和样品身份。

使用方法

  1. 首页 →「新建实验」→「从模板 / 以前的实验」。
  2. 输入实验编号或名称；也可清空搜索，再逐页浏览历史记录。
  3. 选择所需方案，进入新草稿继续编辑。原实验保留，历史运行及采集证据不会复制到新草稿。
