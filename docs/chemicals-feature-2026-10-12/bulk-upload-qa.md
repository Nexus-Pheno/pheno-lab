# SAM Excel upload verification - 2026-10-12

Michael added a downloadable Excel template and bulk molecule-name/SMILES upload to the approved SAM-only portal release. The existing chemistry grants continue to restrict portal, template, preview, commit and original-file reads to Bruce and Michael; ordinary administrators have no bypass. No production bulk import is performed by the agent.

The two-column `SAM Materials` sheet accepts up to 100 literal-text rows in a 2 MB `.xlsx`. The blank template includes bilingual instructions and a public 2PACz example on a separate sheet. It was authored with the spreadsheet artifact runtime, rendered and visually reviewed. No formulas, macros or private laboratory definitions are included. The shipped asset and Downloads copy have identical bytes.

Bounded OOXML parsing rejects formulas, external relationships, macros, embedded objects and excessive expansion/rows. Preview retains Excel row numbers and reports missing, invalid, repeated or existing names; local RDKit generates each valid molecular image. Preview is read-only. The user must explicitly confirm a fully valid file before importing. Imports create new SAMs, preserve an immutable source-workbook hash and per-row provenance, verify COS readback for the workbook and every SVG before committing, and record all material changes and the audit in one transaction. Safe retries and concurrent attempts create one batch. Failed attempts clean only their own unreferenced files; ambiguous database outcomes preserve objects for reconciliation. Public material writers share the same organization lock for final name checks.
