02

Add and save a material新增并保存材料

  1. Choose “Add material row”.A blank row appears at the top.
  2. Enter the material name and category.Select SAM, Additive, Solvent or Other. Use “Add other category” for a custom category; enter its English name and optional Chinese name.
  3. Paste the material’s SMILES.Use the actual structure notation for the molecule. A molecular formula such as C₂H₆O is different from SMILES.
  4. Review the generated structure.Select the row using its atom button. The preview refreshes as you edit. Check that it matches the structure you intended.
  5. Choose “Save row” and check “Saved”.The name/category become available in the material catalogue; SMILES, canonical notation and the stored structure remain private. A preview alone is not a saved row.
  1. 点击“新增材料行”。顶部会出现一个空白行。
  2. 填写材料名称并选择类别。可选 SAM、添加剂、溶剂或其他。需要自定义类别时，点击“添加其他类别”，填写类别英文名称，中文名称可选。
  3. 粘贴材料的 SMILES。请使用该分子的实际结构表示。C₂H₆O 这样的分子式与 SMILES 不同。
  4. 核对自动生成的结构图。点击该行的原子图标选择材料。编辑时预览会自动更新，请确认图中的结构与你期望的一致。
  5. 点击“保存此行”，并确认出现“已保存”。名称与类别可供实验材料库使用；SMILES、规范化表示及保存的结构图仍为私有。仅出现预览图不代表材料已经保存。

Review existing definitions and handle errors核对现有定义与处理错误

  • “SMILES needed”: supply the correct structure notation before saving.
  • “Not yet validated”: an existing definition was preserved. Review its notation and preview, then save the row to validate and store its image.
  • Invalid SMILES: correct the notation before saving. Validation failure retains the draft; it does not save a misleading structure.
  • Duplicate name: search for the existing material before creating another row.
  • Row changed / save conflict: keep a copy of your edits, refresh and review the latest row before applying them.
  • Save/network failure: your on-screen draft is retained, but it is not automatically queued or stored across reloads. Preserve your edits before refreshing.
Structure generation uses local RDKit, without an LLM API or token charge. Valid notation describes the submitted molecular graph; it does not prove the identity, purity or batch composition of a supplied material.
  • “需填写 SMILES”：填写正确的结构表示后才能保存。
  • “尚未验证”：原有定义已保留。请核对 SMILES 和预览图，再保存该行，以完成验证并保存结构图。
  • SMILES 无法验证：先修正表示再保存。验证失败会保留草稿，不会保存错误的结构图。
  • 材料名称重复：先搜索已有材料，避免重复新增。
  • 材料已被修改／保存冲突：先复制保留自己的编辑，再刷新核对最新记录后重新修改。
  • 保存或网络失败：页面中的草稿会保留，但不会自动排队保存，也不会在刷新后自动恢复。刷新前请保留编辑内容。
结构图由本地 RDKit 生成，不调用 LLM API，不产生模型 token 费用。表示通过验证说明提交的分子图可解析，并不证明实际材料的身份、纯度或批次组成。
05

Find materials and use the structure view查找材料与使用结构视图

Search by material name. The registry shows 40 saved materials per page; use the page controls to browse the rest. Edit existing rows directly and save only the changes you intend.

On desktop, rows and the structure preview sit side by side. You can resize, hide or focus the preview and use “Reset view” to restore the layout. On a phone or tablet, use “Inspect structure” and “Return to rows” to switch views.

“Export for analysis” downloads private chemistry definitions for authorized analysis. Keep that file within the approved chemistry access boundary.

可按材料名称搜索。列表每页显示 40 条已保存材料，使用翻页控件查看其余记录。现有记录可直接按行编辑，只保存你确实要更改的内容。

桌面端可并排查看材料行与结构预览。你可以调整预览区域宽度、隐藏或聚焦预览，点击“重置视图”恢复布局。手机和平板通过“查看结构”与“返回材料行”切换视图。

“导出分析数据”可下载私有化学定义，供获授权的分析使用。请将下载文件限制在已批准的化学数据访问范围内。
